# Instrucciones

1. Instala las extensiones **Python** y **Wokwi Simulator** en Visual Studio Code.
2. Instala las dependencias: `pip install -r requirements.txt`.
3. Abre la paleta de comandos con **F1** y ejecuta **Wokwi: Start Simulator**.
4. En la terminal, desde la carpeta del proyecto, ejecuta: `python -m app.main`.
5. Para crear el reporte después de recibir datos, ejecuta: `python -m app.report`.
